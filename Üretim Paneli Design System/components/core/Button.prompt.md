One-line: the standard action control — use `primary` only for the single most important action on a screen ("Kaydet", "Veri Girişi").

```jsx
<Button variant="primary" icon="save">Kaydet</Button>
<Button icon="download">Excel'e Aktar</Button>
<Button variant="ghost" size="sm" icon="sliders-horizontal">Filtre</Button>
```

Variants: primary / secondary / ghost / danger. Sizes: sm 30px, md 36px, lg 42px. On the plant-floor tablet use `lg`.
